# GitHub API Tool Experiment Report

## Experiment Steps
1. **Exploring GitHub Projects:**  
   Reviewed GitHub Projects to identify available tracking features and observed how issues move through the workflow.
2. **Researching Tools:**  
   Researched open-source tools like "GitHub Projects Burndown Chart", "GitHub Burndown Chart", and "Burndown for GitHub Projects".
3. **Tool Setup and Report Generation:**  
   Selected one of the tools, set it up, and generated sample burndown charts to visualize sprint progress.

## Findings
- **Setup:** The tool was straightforward to configure with the GitHub API.
- **Reports:** The generated burndown charts clearly showed sprint progress and remaining work.
- **Usefulness:** The tool can help identify trends and bottlenecks, though there are some limitations in customization.

The experiment demonstrates that an open-source GitHub API tool is a useful addition to GitHub Projects. It provides valuable data for sprint tracking and can help Focus Bear make data-driven improvements to their Agile processes.
