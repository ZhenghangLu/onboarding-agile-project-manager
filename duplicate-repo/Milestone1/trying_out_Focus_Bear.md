# Focus Bear Feedback

## First Impression
This app has a very cute logo, which is very friendly. However, the app will enforce its presence over all applications even before any time settings have been configured.

## Difficulties
- Selection buttons lack clear feedback.
- Option logic is confusing.
- The user guide isn’t clear, making it hard to recall session settings.
- Too many pop-ups can be overwhelming.

## One-Sentence Description
Focus Bear is an app which blocks distractions and guides user for better productivity.

## Suggested Improvements
- Add selection feedback (e.g., a dot in the button).
- Simplify option logic and improve the user guide.
- Reduce pop-ups for a smoother experience.
- Use vector graphics for sharper icons.
